# أدوية أمي — نسخة GitHub Pages

هذه الحزمة جاهزة للنشر على GitHub Pages. ملفاتها عامة **ولا تحتوي بيانات الأدوية أو التحاليل الشخصية**.

## رفع الملفات من الآيفون أو الكمبيوتر
1. افتح github.com وأنشئ مستودعًا عامًا جديدًا؛ مثل `adwiyat-ummi`.
2. ادخل المستودع ثم **Add file → Upload files**.
3. فك ضغط ملف ZIP على جهازك ثم ارفع **جميع الملفات الثمانية** الموجودة بداخله مباشرة إلى جذر المستودع؛ لا ترفع ملف ZIP وحده.
4. اضغط **Commit changes**.
5. افتح **Settings → Pages → Build and deployment → Source: Deploy from a branch**؛ اختر `main` والمجلد `/ (root)` ثم **Save**.
6. رابط الموقع عادة: `https://USERNAME.github.io/adwiyat-ummi/` مع تغيير اسم الحساب والمستودع.
7. افتح الرابط في Safari على الآيفون؛ **مشاركة → إضافة إلى الشاشة الرئيسية**.

## نقل بياناتك القديمة دون رفعها للعلن
- افتح التطبيق القديم أولًا، ثم **الإعدادات → حفظ نسخة احتياطية**، أو انسخ نص JSON إلى «الملاحظات».
- افتح نسخة GitHub Pages الجديدة؛ **الإعدادات → استيراد نص نسخة / استيراد JSON**.
- راجع العدد والأسماء واضغط **تأكيد الاستيراد**، ثم أغلق التطبيق وافتحه للتأكد من استمرار البيانات.
- لا ترفع JSON الشخصية إلى مستودع GitHub؛ تبقى محفوظة فقط في مساحة تخزين الموقع على جهازك.
- قد لا تتشارك نسخة Safari والنسخة المثبتة على الشاشة الرئيسية البيانات تلقائيًا. لذلك استخدم الاستيراد داخل النسخة التي ستعتمدها.
- إذا تغير رابط الموقع أو حذفت بيانات المتصفح أو أزلت التطبيق، قد تضيع البيانات المحلية؛ احتفظ بنسخ JSON خارج التطبيق.

## التحديثات لاحقًا
استبدل الملفات التي تغيرت (عادة `index.html` ومعها `sw.js` إذا تغير اسم نسخة التخزين المؤقت) في **نفس المستودع ونفس الرابط**. احتفظ بنسخة JSON قبل التحديث الكبير. التغييرات قد تظهر بعد إعادة فتح التطبيق واتصال الجهاز بالإنترنت.

## ملاحظات مهمة
- GitHub Pages يستضيف ملفات HTML ثابتة؛ التطبيق نفسه لا يحتاج سيرفر ولا يرفع البيانات الطبية تلقائيًا.
- أي شخص لديه رابط المستودع يستطيع الاطلاع على ملفات HTML/JS، لذلك لا تضع أي معلومات شخصية أو أسرار في الملفات المنشورة.
- التطبيق يعرض مواعيد متابعة إدارية بناءً على إدخالاتك؛ لا يستخدم لتقرير الجرعات الطبية أو بديلًا عن الإرشاد الطبي.
- إذا تغيرت الكميات أو مواعيد الصرف، يجب تحديث أحداث التقويم القديمة يدويًا حتى لا تبقى التنبيهات المكررة.
